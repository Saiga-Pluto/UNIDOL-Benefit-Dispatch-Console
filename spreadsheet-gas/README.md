# Bombs! 特典メール送信 Apps Script

## スプレッドシートの列

| 列 | 内容 |
| --- | --- |
| A | 送信先メールアドレス |
| B | 宛名 |
| C1 | メッセージ動画など、1つ目の特典の見出し |
| C2以降 | 1つ目の特典の宛名、担当者名など |
| D2以降 | 1つ目の特典リンク |
| E1 | 待ち受け画像など、2つ目の特典の見出し |
| E2以降 | 2つ目の特典の宛名、担当者名など |
| F2以降 | 2つ目の特典リンク |
| G2以降 | 送信対象を選ぶチェックボックス |

本文には、以下のように入ります。

```text
[メッセージ動画]
あやか
特典リンク
[待ち受け画像]
りな
特典リンク
```

1つ目の特典は、見出しと対象行の値がある場合だけ本文に入ります。
2つ目の特典は、E列とF列の同じ行に両方の値がある場合だけ本文に入ります。どちらか片方でも空の場合、以下の部分は本文に入りません。

```text
[待ち受け画像]
りな
特典リンク
```

送信後は以下の列を自動で使います。

| 列 | 内容 |
| --- | --- |
| H | 送信ステータス |
| I | 送信日時 |
| J | エラー内容 |

## 使い方

このコードは、スプレッドシートに紐づいた Apps Script に置いた場合にメニューから使えます。

現在の clasp 設定の `scriptId` はスタンドアロンの Apps Script プロジェクトです。そのままだと、どのスプレッドシートを開き直しても「特典メール」メニューは出ません。

メニューから使う場合は、送信対象のA-F列が入っているスプレッドシートを開き、`拡張機能` → `Apps Script` から紐づき済みの Apps Script にこの `Code.js` の内容を入れてください。

紐づき済みの Apps Script に入れた後の手順:

1. 送信対象のスプレッドシートを開き直す。
2. 上部メニューの「特典メール」から「チェックボックスを準備」を実行する。
3. G列でメールを送りたい人だけチェックする。
4. 「選択行をプレビュー」を実行して本文を確認する。
5. 問題なければ「チェック済みの未送信者に送信」を実行する。

G列にチェックがあり、H列が「送信済み」ではない行だけ送信されます。再送したい場合は、その行のH列を空にしてから実行してください。

初回実行時は Google の権限承認が必要です。実際の送信元メールアドレスは、この Apps Script を実行する Google アカウントになります。`info@bombstsukuba.com` は返信先と署名に設定しています。

## Webアプリ化する場合の方針

GitHubで管理するWebアプリにする場合も、メール送信だけはブラウザ単体では安全に実行できません。送信用の秘密情報やGoogle認証をフロントエンドに置けないためです。

現実的な構成は以下です。

| 役割 | 推奨構成 |
| --- | --- |
| 画面 | GitHub Pages、Vercel、Netlifyなどで公開するWebアプリ |
| シート取込 | CSVまたはExcelファイルをアップロードしてA-F列を読み取る |
| プレビュー | ブラウザ上で件名・本文テンプレートと各行データを合成して確認 |
| 送信対象選択 | Web画面上のチェックボックスで選択 |
| メール送信 | Google Apps Script Web App、またはGmail APIを使うバックエンド |
| 送信履歴 | アップロード元ファイルとは別に、Webアプリ側でCSV出力またはDB保存 |

変数に詳しくない人向けには、本文テンプレートを直接編集させるより、以下のような入力欄に分けるのが安全です。

| 入力欄 | 例 |
| --- | --- |
| 件名 | UNIDOL2026Summer関東予選1日目の特典送付のお知らせ |
| 冒頭文 | この度は... |
| 1つ目の特典見出し | メッセージ動画 |
| 1つ目の本文列 | C列とD列を使う |
| 2つ目の特典見出し | 待ち受け画像 |
| 2つ目の本文列 | E列とF列を使う |
| 署名 | 筑波大学アイドル研究会 Bombs! |

送信上限対策として、画面上で「今回送信する件数」を常に表示し、100件を超えたら送信ボタンを押せないようにします。
